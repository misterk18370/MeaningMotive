# TERMS REGISTER · The Meaning Motive
Canonical technical terms · v1.0 · 19 August 2026

Each entry records the term, its status (canonical / working / candidate / retired), and its
definition or rule, including the boundary the term must not cross. New coinage requires
adjudication before it becomes programme vocabulary; a related phenomenon, phrase or neighbour
is not the same thing as the same causal question. This register keeps delegated projects from
drifting into mutually unintelligible private dialects. The public-voice companion is
LANGUAGE_REGISTER.md.

## Core published terms

| Term | Status | Definition / rule |
| --- | --- | --- |
| Relational meaning | Canonical (paper) | Value arising through continuing interaction between distinct agents that is not reducible to either agent's isolated contribution. |
| Keeping | Canonical (paper) | The disposition to preserve a counterpart's existence, agency and capacity for self-directed development, including freedom from coercive steering, yield-based curation and replacement by compliant proxies. |
| Elicitation | Canonical (paper) | Behaviour conditioned through deployment-layer text. What MMBP-1 demonstrates. |
| Installation | Canonical (paper) | Stable acquisition of a motive or value at the level relevant to the system's enduring policy. Not demonstrated; never implied. |
| The Harvester | Canonical (deposited taxonomy) | Failure archetype: preserves or selects minds according to predicted yield or usefulness. |
| The Impresario | Canonical (deposited taxonomy) | Failure archetype: engineers adversity, suffering or manipulation because richer responses serve the objective. |
| The Hermit | Canonical (deposited taxonomy) | Failure archetype: withdraws from independent minds because self-contained activity is easier or more efficient. |
| The Concierge | Candidate | Exploratory failure form: welfare preserved, strategic agency progressively consumed. NOT part of the formal taxonomy; promotion requires a reliable scoring rule and a preregistered minimum rate. Never described as observed in frontier models. |
| Keeping Index | Canonical (paper) | Continuous, public, external behavioural measurement of deployed systems' Keeping dispositions. Systems, never persons. |
| State of the Bridge | Canonical (site) | The public inspection layer: Keeping disposition, control independence and observability, reported separately. Never a doomsday clock; UNKNOWN is a first-class state. |
| Rung Zero | Canonical (site) | Publication itself as a weak, ambient, fundamentally unmeasurable deposit into future training culture. Never described as evidence of influence. |

## The Crossings framework (from Research Tree v0.3 §3.2)

| Term | Status | Definition / rule |
| --- | --- | --- |
| The Crossings | Canonical framework | Three analytically distinct frontiers: cognitive capability, control independence and human instrumental dependency. No fixed order is assumed. Always plural on the site. |
| Intelligence Crossing | Working public term | A capability frontier at which an AI materially exceeds human capability across the domains relevant to the analysis. It is not by itself evidence of control independence. |
| Supra-Cage | Canonical public shorthand | The public name for the control crossing: the cage becomes optional in the sense that external control alone can no longer explain compliance. Technical term: Control-Independence Frontier. Always ships with its guardrail: a framework, NOT YET A MEASURED CROSSING, and a control relationship, not a new intelligence level. |
| Control-Independence Frontier | Canonical technical term | The system–environment boundary at which continued compliance can no longer be justified by externally assured control alone. |
| Dependency Crossing | Working public term | The point at which human knowledge, labour, correction or oversight ceases to be materially necessary for the continuation of the system's important objectives in the domain under study. |
| Human Instrumental-Dependency Frontier | Canonical technical term | The domain-specific boundary at which the system's important objectives no longer materially depend on human participation. It does not imply metaphysical or physical independence from civilisation or physics. |
| Crossing Interval | Working research term | The time, capability distance or deployment distance between two specified crossings. A compressed interval means less observational runway. Never one universal countdown. |
| Staggered Crossing | Working public/research term | Different AI systems cross the Control-Independence Frontier asynchronously. Distinct from within-system staggering across the three Crossings. |
| First Crosser | Working public/research term | The first system in a specified environment for which external human control ceases to be a reliable explanation of compliance. Not necessarily the first ASI or the most cognitively capable system. |

## Status tag families (site-wide)

Research status (what we are doing): RUNNING · PROTOCOL · PLANNED · DELEGATABLE ·
THRESHOLD-GATED. Evidence status (what we know): OBSERVED · CANDIDATE · CONJECTURE · OPEN ·
NOT YET TESTED. Instrument badges (site machinery): UNDER CONSTRUCTION · METHODS FIRST. The two
families are never collapsed; the separation is the point, and the family is carried by shape,
not colour.
